Мини-монитор: показывает выбранный участок экрана в реальном времени
в отдельном плавающем окне (картинка в картинке).

Как пользоваться:
  1. Запусти:  python mini_monitor.py
  2. Экран накроет прозрачная рамка — растяни прямоугольник вокруг
     нужного участка (например, миникарты) и отпусти кнопку мыши.
  3. Появится окно-виджет с этой областью в реальном времени.
  4. Управление окном:
       - перетаскивание мышью  — двигать окно
       - колесо мыши           — менять размер (масштаб)
       - двойной клик          — включить/выключить режим "прозрачный фон"
                                 (скриншот-пиксели только с этого участка)
       - ПКМ                   — меню: выбрать зону заново, поверх всех
                                 окон, поверх игры, выход
  Позиция/размер/выбранная зона сохраняются в mini_monitor.json
